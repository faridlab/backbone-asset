# Changelog

All notable changes to this project are documented here.
The format is based on [Keep a Changelog](https://keepachangelog.com/) and this project
adheres to [Semantic Versioning](https://semver.org/).

## [0.3.0] - 2026-07-30

Delivers the fixed-asset bounded context found missing by the
2026-07-30 council review (`docs/council/`): the GL-safe lifecycle engine is now the
sole write surface, and the published contract is real.

### Changed / Breaking
- The safe default route composer is now `AssetsModule::read_only_routes()` — full CRUD on the
  `AssetCategory` master and **read-only** on the two engine-owned financial tables
  (`Asset`, `AssetDepreciationEntry`). Compose a deployment as
  `module.read_only_routes().merge(module.lifecycle_routes())`.
- `AssetsModule::all_crud_routes()` is the **generated** full-CRUD surface (every entity, writes
  included). It is regenerated by `metaphor make`, so do NOT rely on it for the safe default —
  use `read_only_routes()`. (Generic writes on the financial tables would bypass the engine and
  silently desync the books from the GL.)
- `AssetsModule::lifecycle_routes()` requires a `GlPostSink`; it panics at startup if none is
  supplied. Add `.with_gl_sink(...)` to the builder.

### Added
- Validated, GL-backed lifecycle write surface — `register` / `activate` / `depreciate` /
  `dispose` — mounted via `AssetsModule::lifecycle_routes()`. Compose a deployment as
  `module.read_only_routes().merge(module.lifecycle_routes())`.
- `AssetsModuleBuilder::with_gl_sink(Arc<dyn GlPostSink>)` and
  `.with_event_sink(Arc<dyn AssetEventSink>)` (defaults to `LoggingSink`).
- `AssetsModule::query_service()` — the published read contract `AssetsQueryService` is now
  implemented over the repos/DTOs. (The `exports` module was emitted by the generator but never
  declared in `lib.rs`, so it compiled to nothing; it is now a live, published surface.)
- Lifecycle events `AssetActivated` / `DepreciationPosted` / `AssetDisposed` published via
  `application::service::AssetEvent`.
- DB `CHECK` invariants (migration `20260426220007`): `accumulated_depreciation ≤ gross −
  salvage`, `net_book_value = gross_purchase_amount − accumulated_depreciation`, and a draft's
  accumulated depreciation equals its opening/legacy amount.

### Regen-safe
- After `metaphor make` regenerated the module files (rewriting `lib.rs`'s generated `impl`
  region and resetting the `exports` CUSTOM blocks), the hand-written delivery was relocated to
  homes the generator never touches: entity→DTO `From` impls into `assets_query_service.rs`, and
  `read_only_routes` / `lifecycle_routes` / `query_service` into a new `assets_module_ext.rs`
  (a second `impl AssetsModule` block), declared via a preserved `lib.rs` CUSTOM block.

### Fixed
- Mojibake em-dashes in `Cargo.toml` comments.

### Known issues
- `tests/integrity_probes.rs::ip6_dispose_vs_depreciation_serialize` is a flaky concurrency test
  (pre-existing, unrelated to this release): when disposal wins the row-lock race before any
  depreciation posts, `accumulated_depreciation = 0` yields a zero-amount accum-dep debit line in
  the disposal posting, which can be rejected — stranding the fixed-asset balance. The engine and
  the test are otherwise unchanged; a focused fix is tracked separately.
